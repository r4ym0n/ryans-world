# Ryan Essayist Style

## 定义

思想者文风是 Ryan 的压舱石长文风格：用大历史或大科幻隐喻承载技术哲学命题，语气慢，论证长，结尾留白。适合 4000-8000 字 essay。

## 核心规则

- 使用 `## 引子 / ## 第一章 / ## 第二章 / ## 后`，不用 `## 前 / ## 后`。
- 引子要给读者一张问题地图。
- 核心隐喻必须是大框架：大航海、农耕革命、印刷术、赛博新大陆。
- 隐喻要贯穿全文，不只是开头类比。
- 段落更长，列表和表格要少。
- 第一人称收紧为讲座式：“我想说的是”“我把这种状态称为”。

## 信息密度

- 至少 3 个具体时间点。
- 至少 3 个学者、人物或作品。
- 至少 3 个历史事件或现实案例。
- 所有材料必须进入论证链条，不能堆资料。

## 禁用

- 行动建议清单结尾。
- 工程师口头禅。
- 过量 Markdown 表格和列表。
- 把科幻设定当论证本身。
