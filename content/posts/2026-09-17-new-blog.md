我又换博客系统了。

## 为什么折腾第三次

WordPress 太重，Hugo 太静。前者要养服务器，后者把"写"变成了"提交构建"。我真正想要的只有一件事：**在任何地方，打开就能写，写完就能发，发完不用管。**

这次的答案出奇地简单：

- 写作在 Obsidian 里进行（包括手机端）
- 内容就是纯 Markdown 文件，躺在一个文件夹里
- git 自动同步到 GitHub
- Vercel 自动构建部署

日常维护为零。想写就写。

## 技术选型

- **Astro**：静态生成，内容即 Markdown，快且无需服务器
- **Vercel**：push 即部署，免费额度对个人博客绰绰有余
- **Obsidian**：写作界面，移动端也能用
- **Giscus**：基于 GitHub Discussions 的评论（即将接入）

## 内容边界

不是所有笔记都会发到博客上——vault 里上千篇是私有的思考过程。博客是策展后的公开表达，边界就是 `posts/` 这个文件夹。进这个文件夹的，才见光。
